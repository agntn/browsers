## One call, a different answer from each

Same URL, same tool, same minute. This is `browsers_scrape` on `https://example.com` through every provider, recorded with real keys and kept exactly as it came back.

::scrape-walk
::

Look at the sizes. Kernel and Browserless hand back the raw HTML, stylesheet and all, for a page with a few sentences on it. Steel, Browserbase and Hyperbrowser answer in markdown. Playwright gives you `innerText`. Cloudflare gives markdown with a front matter block on top. Anchor says no.

None of that is a bug in this package. It's what the vendors return, and hiding it behind a fake "normalized" text would be worse. What the package does promise is the shape: a `ScrapeResult` with `url` and whichever of `html`, `markdown`, `text`, `title` and `statusCode` the vendor filled.

## In TypeScript

```ts
import { create } from "@agntn/browsers";

const provider = await create("cloudflare");
const page = await provider.scrape("https://example.com", {
  formats: ["markdown", "html"],
  waitFor: "main",
});

page.markdown;
page.html;
page.statusCode;
```

The options are `formats`, `waitFor` (a CSS selector), `waitForNetworkIdle`, `screenshot`, `maxChars`, `timeout`, `script` and `headers`. Not every vendor honours every one, so treat them as requests. Cloudflare is the generous one here. Ask it for `html` and `markdown` together, or add `screenshot: true`, and all of it comes out of one render.

## Session or no session

`capabilities().statelessScrape` says whether a provider scrapes without a session. Kernel is the one that doesn't. `provider.scrape(url)` there wants a session as its third argument:

```ts
const kernel = await create("kernel");
const session = await kernel.createSession();
try {
  const page = await kernel.scrape("https://example.com", {}, session);
} finally {
  await kernel.releaseSession(session.id);
}
```

The CLI and the agent tools do exactly this for you, `finally` included. Forget the release in your own code and the vendor keeps billing the browser until its own timeout. Don't.

## The agent's version

`browsers_scrape` asks for markdown and hands the model text first, then markdown, then HTML, whichever exists. It stops at 20 000 characters unless you pass `maxChars`, up to 200 000, and says how much it cut:

```text
[truncated 4200 of 24200 characters]
```

So a model never gets a silent half page. It gets told.

## Kitesurf

Cloudflare's Browser Run has a second engine, Kitesurf. Opt in with `create("cloudflare", { browser: "kitesurf" })`, `--browser kitesurf` in the CLI, or `browser: "kitesurf"` on a tool. Leave it out and Cloudflare stays on Chromium.
