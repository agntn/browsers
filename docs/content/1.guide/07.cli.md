One install gives you the `browsers` command. After `pnpm add` it's `pnpm exec browsers`, or install it once with `pnpm add -g @agntn/browsers`. Or skip installing entirely:

```bash
npx @agntn/browsers scrape https://example.com -p playwright
```

## Commands

| Command         | What it does                               |
| --------------- | ------------------------------------------ |
| `scrape`        | Rendered page, markdown if the vendor has it |
| `screenshot`    | Image to a file, the page or one element   |
| `pdf`           | The page printed to a PDF file             |
| `crawl`         | Follow links, or wait for a crawl job again |
| `links`         | Unique hrefs, one per line                 |
| `accessibility` | Roles, names and states, one per line      |
| `extract`       | Structured data from a prompt              |
| `search`        | Web search through Hyperbrowser            |
| `session`       | `create`, `list` and `release`             |
| `providers`     | Who is configured and what they can do     |
| `mcp`           | MCP server on stdio                        |

`browsers <command> --help` has every flag. The ones you'll type most: `-p` for the provider, `-o` for the output file, `-f` for the format.

## Who answers

Skip `-p` and the first configured provider in registry order that can do the job gets the call. Steel if its key is set. Playwright if nothing else is. `links` on a Steel setup skips Steel, which has no links route. `scrape`, `screenshot`, `pdf`, `crawl`, `extract`, `search`, `accessibility` and `session create` look past a provider the same way. Only `ANCHOR_API_KEY` set? `scrape` walks past Anchor, which doesn't scrape, and lands on Playwright. Name a provider with `-p` and you get that one, refusal included.

```bash
browsers providers
```

```text
● steel           scrape screenshot(sess) sessions cdp
● browserbase     scrape sessions cdp
● kernel          scrape(sess) screenshot(sess) navigate evaluate sessions cdp
● browserless     scrape screenshot element navigate evaluate sessions cdp pdf
● hyperbrowser    scrape screenshot sessions cdp crawl search extract
● anchor          screenshot(sess) sessions cdp
● cloudflare      scrape screenshot element sessions cdp crawl pdf links extract accessibility
● playwright      scrape screenshot(sess) element navigate evaluate sessions crawl pdf links
```

A filled dot means that provider's key was in the environment on this run. Playwright is always filled. `(sess)` means the operation needs a session, which the command opens and closes for you.

## Pipes

Status lines like `ℹ Scraping via playwright...` go to stderr. Stdout gets the page and nothing else, so this does what it looks like:

```bash
browsers scrape https://example.com -p playwright -f html > page.html
```

A failure prints one `ERROR` line and exits with 1. Keys in a URL never make it into that line: query params such as `token` or `api_key` show up as `[REDACTED]`.
