Flags come from `capabilities()` on a live instance, read when this site was built. The last column is one recorded `browsers_scrape` of `https://example.com` per provider, so you can see what "scrape" means to each of them. Sort by it. The spread is the whole reason this package exists.

## Picking one

For a first try, or anything on your own machine, [Playwright](/providers/playwright). No key, no bill, real Chromium.

For the most operations behind one key, [Cloudflare](/providers/cloudflare). It's the only one with the accessibility tree and one of two with links.

For search, [Hyperbrowser](/providers/hyperbrowser), because nobody else has it.

For a remote browser you drive yourself over CDP, any of them except Playwright. That's where [Kernel](/providers/kernel), [Browserbase](/providers/browserbase) and [Anchor](/providers/anchor) make more sense than their scrape column suggests.

Missing a vendor? [Custom providers](/guide/custom) is one file.
