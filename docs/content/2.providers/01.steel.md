::provider-facts{name="steel"}
::

Steel scrapes in one call to `/v1/scrape`, no session involved, and that's why it sits first in the registry: set `STEEL_API_KEY` and it's the default for everything it can do.

Ask for markdown and Steel answers in markdown. The tool always asks. So a model gets the words of the page, not `<html lang="en"><head>…` and a whole stylesheet. On example.com that's a thirteenth of the size. The catch? Steel takes its time converting. It was the slowest in the recording. Plain HTML comes seconds sooner, and `scrape()` without `formats` still gets it. `cleanedHtml` works too. Plain `text` Steel doesn't make.

Screenshots run in a session, which the CLI and the tools open and release for you. Sessions also carry a CDP URL for your own Playwright.
