::provider-facts{name="browserbase"}
::

Browserbase's `/v1/fetch` renders a page and hands back markdown without opening a browser session, so `scrape()` is one call. In the recording it was the tidiest answer of the lot: two sentences and a proper markdown link.

That's about it over REST. No screenshot, no PDF, no crawl. `screenshot()` throws `UnsupportedOperationError` and points you at CDP. Browserbase is built around sessions you drive yourself, and `createSession()` gives you exactly that: an ID and a CDP URL.
