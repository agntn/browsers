title: Kernel
description: Every read runs Playwright inside a live Kernel browser. Scrape and screenshot need a session. Needs KERNEL_API_KEY
---

::provider-facts{name="kernel"}
::

Kernel doesn't have a scrape route. It has browsers. So `scrape()` sends a small Playwright script to `/browsers/{id}/playwright/execute`, `page.goto` then `page.content()`, and that's the scrape. No session, no scrape: it throws until you pass one.

The CLI and the tools handle that. They open a browser, scrape, and release it in `finally`. That round trip is the price of a real browser per call. In the recording only Steel's markdown took longer. Also raw HTML, since that's what `page.content()` returns.

In exchange you get `navigate` and `evaluate` on a live session, and a CDP URL, so Kernel is a good fit when the scrape is only the first step.
