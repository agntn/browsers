title: Browserless
description: HTML from /content and screenshots and PDFs from their own routes. One element by selector. Needs BROWSERLESS_API_KEY

::provider-facts{name="browserless"}
::

Browserless has a REST route per job: `/content` for HTML, `/screenshot` for images, `/pdf` for PDFs. All of them work without a session. `scrape()` is `/content`, so expect the raw page, not markdown.

`screenshot()` takes a `selector` for one element, which not every provider can. A selector the page doesn't have comes back as Browserless's own `Element not found on page!`, with your token redacted in the URL.

Sessions go through `/session`, and `navigate` and `evaluate` connect to that session over CDP. Browserless refuses a second client while it still counts the first, so the package keeps one connection per session open until you release it.

The key goes in the query string, `?token=…`. Every error message shows it as `[REDACTED]`.
