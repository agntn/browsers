::provider-facts{name="anchor"}
::

Anchor doesn't scrape. Ask it anyway and you get this:

```text
browsers_scrape failed: anchor does not support scrape via REST. Connect via CDP for full automation.
```

The row stays in the registry because someone will look for it, and an honest no beats a missing entry. What Anchor does have is sessions with a proxy, a profile and stealth settings, a CDP URL to drive them, and a screenshot tool at `/v1/tools/screenshot`, which the tools run inside a session.
